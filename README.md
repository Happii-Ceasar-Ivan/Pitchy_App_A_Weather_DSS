# Pitchy

**Multi-Source Weather Decision Support System with Adaptive Conversational Agent for Football Safety Protocols**

A planned football weather decision support system that will combine multiple weather sources, assess relevant hazards, and explain safety-related information to football stakeholders. It supports authorized decision-makers and does not replace them.

## Planned technology

- Flutter for Android and Windows applications.
- Supabase and PostgreSQL for backend and database services.
- Vercel for the landing page.
- SQLite or another suitable option for local storage.
- External LLM APIs and retrieval-augmented generation (RAG) over approved safety materials and relevant system information.
- GitHub Releases for binary distribution.

These are plans; they do not indicate that the components are implemented or that unresolved technology choices have been finalized.

## Repository overview

- `apps/flutter_app/` — planned Flutter client structure.
- `backend/` — planned API, weather ingestion, safety assessment, RAG, and AI provider areas.
- `supabase/` — reserved for future functions, migrations, seed material, and tests.
- `landing_page/` — planned landing page structure and public downloads placeholder.
- `config/` — environment-specific configuration guidance placeholders.
- `docs/` — project, security, research, and open decision documentation.
- `scripts/` — reserved for future development, database, and deployment scripts.
- `.github/workflows/` — reserved for future workflow configuration.

## Project status

This repository is currently a project skeleton. Planned components and responsibilities are not necessarily implemented. No application functionality, database schema, security controls, or safety thresholds are established by this skeleton.
